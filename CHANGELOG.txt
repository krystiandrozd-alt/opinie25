
School Opinions WSR - Changelog

-------------------

Initial Release - Production Ready

Added:
- Complete repository structure for Power Platform deployment
- 9 Dataverse table definitions:
  * wsr_school - Schools
  * wsr_section - Classes/Sections
  * wsr_teacher - Teachers
  * wsr_student - Students
  * wsr_studentenrollment - Student enrollments
  * wsr_teacherroster - Teacher rosters

  * wsr_opinion - Individual opinions
  * wsr_studentopinionpackage - Aggregated opinion packages

- 14 Power Automate flows metadata:

  * 8 Opinion workflow flows (Create, Submit, Approve, Reject, Generate PDF, Aggregate, Send, Close)

- 2 Azure Functions:
  * markdown-to-html (Node.js) - Markdown to HTML conversion

- Power Apps model-driven application metadata
  * Complete sitemap structure
  * Forms and views configuration
  * Dashboard definitions

- Power BI dataset configuration
  * 12 predefined measures
  * 3 report pages (Overview, Teacher Performance, Package Status)
  * Row-level security (RLS) definitions

- SharePoint library configurations:
  * SDS_Import - CSV import files
  * OpinionPDFs - Generated PDF documents

- Deployment automation:
  * deploy.ps1 - PowerShell deployment script
  * deploy-config.json - Configuration template
  * post-deployment-steps.md - Detailed post-deployment guide

- Comprehensive documentation:
  * README.md - Complete repository documentation
  * Architecture diagrams
  * Workflow descriptions
  * Setup and configuration guides

- Sample data:
  * school_13001.json - Example school data

Features:
- Full opinion lifecycle automation
- School Data Sync (SDS) integration
- Markdown support for opinion writing
- Automated HTML conversion
- PDF generation and distribution
- Email notifications
- Multi-role security model
- Power BI dashboards and KPIs
- Complete ALM support

Technical Stack:
