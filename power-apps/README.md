# Power Apps

Place the exported Power Apps application here.

## File

- `SchoolOpinionsManager.msapp` - Model-driven application file

## How to Export

1. Open **Power Apps** → **Apps**
2. Select **School Opinions Manager**
3. Click **...** → **Export package**
4. Download the `.msapp` file
5. Place it in this directory

## How to Import

1. Open **Power Apps** → **Apps**
2. Click **Import canvas app**
3. Upload the `.msapp` file
4. Follow the import wizard

## Note

Model-driven apps are typically imported as part of the Dataverse solution. This directory is for standalone exports if needed.

For full deployment, use the solution export from `dataverse/solution/`.
